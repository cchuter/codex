# OsmiFlow

AI-powered coding assistant built on Codex.

## Installation

```bash
npm install -g @osmi/osmiflow
```

## Usage

After installation, you can use OsmiFlow from the command line:

```bash
osmiflow --help
```

### Basic Commands

```bash
# Start an interactive session
osmiflow

# Ask a specific question
osmiflow "explain this codebase to me"

# Use with specific model
osmiflow --model gpt-4 "refactor this function"
```

## Supported Platforms

- macOS (Intel x64)
- macOS (Apple Silicon arm64)  
- Linux (x64)
- Windows (x64)

## Features

- AI-powered code analysis and generation
- Interactive coding assistant
- Multiple model support
- Code refactoring suggestions
- Documentation generation
